# RTL Design & Verification Portfolio

**Author:** B Harinarayanan  

---

## 📌 Project Overview
This repository contains a day-by-day documentation of my progress in learning and implementing RTL Design and Verilog HDL. It includes behavioral modeling codes for various digital circuits, their corresponding testbenches, and simulated output waveforms.

---
Day 1: Basic Combinational Circuits & Adders
Topics Covered: RTL Design basics, Combinational Logic.

Implementations:

Half Adder & Full Adder: Basic building blocks for arithmetic operations.

Ripple Carry Adder: Designed utilizing the foundational Full Adder modules.

BCD Adder: Implemented using the Ripple Carry Adder design.

Files:

Source codes are located in Day1/Design/

Testbenches are located in Day1/Testbench/

Verified simulation results and waveforms are available in Day1/Waveforms/

Day 2: Sequential Circuits & Advanced Combinational Logic
Topics Covered: Sequential Logic, Memory Elements, Decoders.

Implementations:

Flip-Flops: Designed fundamental memory storage elements, specifically SR Flip-Flop and D Flip-Flop.

Universal Shift Register: Implemented a multi-mode shift register capable of shifting data left/right and parallel loading.

2x4 Decoder: Designed a standard 2-to-4 line decoder combinational circuit.

Files:

Source codes are located in Day2/Design/

Testbenches are located in Day2/Testbench/

Verified simulation results and waveforms are available in Day2/Waveforms/
