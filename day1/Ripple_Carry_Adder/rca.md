# 4-Bit Ripple Carry Adder (RCA) using Verilog

## Overview
This project implements a 4-bit Ripple Carry Adder (RCA) using Full Adders in Verilog HDL. The carry generated by each stage is propagated to the next stage, allowing the addition of two 4-bit binary numbers along with an optional carry input.

## Features
- Adds two 4-bit binary numbers
- Supports carry input (Cin)
- Produces 4-bit sum output
- Generates carry output (Cout)
- Includes a testbench for simulation and verification

## Inputs

| Signal | Description |
|----------|-------------|
| A[3:0] | First 4-bit input |
| B[3:0] | Second 4-bit input |
| Cin | Carry input |

## Outputs

| Signal | Description |
|----------|-------------|
| Sum[3:0] | 4-bit sum output |
| Cout | Final carry output |

## Test Cases

| A | B | Cin |
|---|---|-----|
| 0000 | 0000 | 0 |
| 0011 | 0100 | 0 |
| 1111 | 0001 | 0 |
| 0111 | 0111 | 1 |
| 1010 | 0101 | 0 |

## Working Principle
A Ripple Carry Adder consists of four Full Adders connected in series. The carry output from each Full Adder is connected to the carry input of the next Full Adder. The carry "ripples" through the stages until the final carry output is generated.


## Result
The 4-bit Ripple Carry Adder successfully performs binary addition and generates the correct sum and carry outputs for all test cases.
