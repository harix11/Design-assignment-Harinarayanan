# FIFO-Based Data Synchronization Between Two Machines

## Overview

This project demonstrates the use of a FIFO (First-In First-Out) buffer to synchronize data transfer between two digital machines operating at different processing rates.

- **Machine 1** produces an 8-bit output every clock cycle.
- **Machine 2** can accept/process data only once every 3 clock cycles (implemented as a 3-state FSM).

Without buffering, Machine 2 misses incoming data because Machine 1 generates data faster than it can be consumed.

A FIFO is inserted between the two machines to temporarily store incoming data and release it in the correct order whenever Machine 2 is ready.

---

## Problem Statement

Machine 1 generates data continuously:

| Clock Cycle | Data |
|------------|------|
| 1 | 00 |
| 2 | 01 |
| 3 | 02 |
| 4 | 03 |
| 5 | 04 |
| 6 | 05 |
| ... | ... |

Machine 2 reads data only every third clock cycle.

Without a FIFO:

- Data generated during the first two clock cycles is lost.
- Only data available when Machine 2 becomes ready is captured.

This results in data loss and incorrect sequencing.

---

## FIFO-Based Solution

A FIFO buffer is placed between the two machines.

### Write Operation
- Machine 1 writes data into the FIFO every clock cycle.

### Read Operation
- Machine 2 reads data from the FIFO once every 3 clock cycles.

Since FIFO preserves the order of arrival, all data is eventually delivered without loss.

---

## Expected Output Timing

| Data | Output Clock Cycle |
|--------|------------------|
| 00 | 3 |
| 01 | 6 |
| 02 | 9 |
| 03 | 12 |
| 04 | 15 |
| 05 | 18 |

Thus:

- First input appears at the output after 3 clocks.
- Second input appears after 6 clocks.
- Third input appears after 9 clocks.
- No data is lost.

## Inputs

| Signal | Description |
|----------|-------------|
| clk | System clock |
| rst | Reset signal |
| data_in[7:0] | 8-bit input from Machine 1 |

---

## Outputs

| Signal | Description |
|----------|-------------|
| final_out[7:0] | Output from Machine 2 |
| out_valid | Indicates valid output data |

---

## Working Principle

1. Machine 1 continuously generates 8-bit data.
2. FIFO stores incoming data sequentially.
3. Machine 2 FSM cycles through three states.
4. Data is read from FIFO only when the FSM reaches its output state.
5. FIFO ensures all data is delivered in the same order it was received.

---

## Simulation Result

The waveform confirms that:

- Data values are stored successfully in the FIFO.
- Outputs appear periodically after every three clock cycles.
- Data sequence is preserved.
- No data is skipped or overwritten.
- `out_valid` is asserted whenever a valid output is available.

Observed output sequence:

```text
00 → 01 → 02 → 03 → 04 → 05 → 06
```

Each value is produced at intervals corresponding to the 3-cycle processing rate of Machine 2.

---

## Applications

- Clock domain synchronization
- Processor-to-peripheral communication
- UART buffering
- Streaming data systems
- High-speed producer / slow consumer architectures
